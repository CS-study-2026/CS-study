# **9-2.** 그렇다면 3가지만 충족하면 왜 Deadlock 이 발생하지 않을까요?

> 하나라도 빠지면 Deadlock은 절대 발생할 수 없습니다.

## 예시 

### 1️⃣ 순환 대기가 없는 경우

- A → B 자원 기다림

- B → C 자원 기다림

- C → 아무도 안 기다림

👉 사이클이 없음 → 언젠가는 풀림 → Deadlock ❌

### 2️⃣ 비선점이 없는 경우

- OS가 강제로 자원을 회수 가능

👉 누군가 자원을 뺏어서 해결 가능 → Deadlock ❌

### 3️⃣ 점유 대기가 없는 경우

- 한 번에 모든 자원을 요청하도록 설계

👉 중간에 기다리는 상황 자체가 없음 → Deadlock ❌

3개만 만족하면:

→ **어딘가에서 “탈출 경로”가 존재**

→ 시스템이 결국 진행 가능 (progress 가능)
