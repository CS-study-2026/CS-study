# 21-1. LRU 알고리즘은 어떤 특성을 이용한 알고리즘이라고 할 수 있을까요?

# 21-1. LRU 알고리즘은 어떤 특성을 이용한 알고리즘이라고 할 수 있을까요?

## 답변

LRU(Least Recently Used)는 **시간 지역성(Temporal Locality)** 을 이용한 페이지 교체 알고리즘입니다.

시간 지역성이란 **최근에 사용된 데이터는 가까운 미래에도 다시 사용될 가능성이 높다**는 특성을 의미합니다.

LRU는 이러한 특성을 활용하여 최근에 사용된 페이지는 메모리에 유지하고, 가장 오랫동안 사용되지 않은 페이지를 교체 대상으로 선택합니다.

---

# 시간 지역성(Temporal Locality)

## 정의

> 최근에 접근한 데이터나 명령어는 가까운 미래에 다시 접근될 가능성이 높다.

---

## 예시

```java
for(int i = 0; i < 1000; i++) {
    sum += arr[i];
}
```

반복문이 실행되는 동안

```plain text
i
sum
arr
```

와 같은 변수와 데이터가 지속적으로 참조됩니다.

즉,

```plain text
최근 사용
↓
가까운 미래에 다시 사용
```

되는 패턴이 반복됩니다.

---

# LRU는 이를 어떻게 활용할까?

LRU는 다음과 같이 가정합니다.

```plain text
최근에 사용된 페이지
→ 앞으로도 사용될 가능성이 높음

오랫동안 사용되지 않은 페이지
→ 앞으로도 사용되지 않을 가능성이 높음
```

따라서 페이지 교체가 필요할 때

```plain text
가장 오랫동안 참조되지 않은 페이지
↓
교체
```

하는 전략을 사용합니다.

---

# 왜 효과적인가?

실제 프로그램은 다음과 같은 특징을 가집니다.

- 반복문 수행

- 함수 호출

- 스택 사용

- 캐시 데이터 재사용

이러한 동작들은 모두 시간 지역성을 만들어냅니다.

그래서 LRU는 미래의 참조 정보를 알 수 없는 실제 환경에서도 OPT(Optimal)에 가까운 성능을 보입니다.

---

# 지역성(Locality)의 종류

## 시간 지역성 (Temporal Locality)

> 최근 사용한 데이터는 다시 사용될 가능성이 높다.

예시

```java
sum += arr[i];
```

반복문 내 변수 사용

---

## 공간 지역성 (Spatial Locality)

> 특정 주소를 참조하면 인접한 주소도 함께 참조될 가능성이 높다.

예시

```java
arr[0]
arr[1]
arr[2]
arr[3]
```

배열 순차 접근
