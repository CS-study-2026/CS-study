# **7-3.** 동시성과 병렬성의 차이에 대해 설명해 주세요.

동시성과 병렬성은 모두 "여러 작업이 동시에 일어나는 것"처럼 보이지만, **CPU가 일을 처리하는 구조**가 다릅니다.

---

# 1. 동시성 (Concurrency)

- **개념:** 여러 개의 작업이 **마치 동시에 일어나는 것처럼 보이게** 하는 것.

- **작동 방식:** 싱글 코어(Single Core) CPU에서 여러 프로세스/스레드가 짧은 시간 단위로 CPU를 번갈아 가며 사용합니다. (Context Switching 활용)

- **핵심 키워드:** 논리적 개념, 시분할(Time-sharing), 구조적 설계.

- **목적:** CPU의 유휴 시간(시스템·기계가 가동 준비가 되었지만 실제 작업을 수행하지 않는 기간)을 최소화하고, 사용자에게 여러 작업이 동시에 실행되는 듯한 경험(응답성)을 제공하는 것.

# 2. 병렬성 (Parallelism)

- **개념:** 여러 개의 작업이 **물리적으로 동시에** 실행되는 것.

- **작동 방식:** 멀티 코어(Multi Core) CPU에서 각 코어가 서로 다른 작업을 실제로 같은 시간에 처리합니다.

- **핵심 키워드:** 물리적 개념, 멀티 코어, 하드웨어 성능.

- **목적:** 많은 양의 계산 작업을 여러 코어에 분산시켜 전체적인 처리 속도를 높이는 것.

# 3. 동시성 vs 병렬성

| **구분** | **동시성 (Concurrency)** | **병렬성 (Parallelism)** |
| --- | --- | --- |
| **CPU 코어 수** | 싱글 코어에서도 가능 | 반드시 멀티 코어 필요 |
| **처리 방식** | 작업을 잘게 쪼개어 번갈아 실행 | 여러 작업을 각 코어에서 실제 동시 실행 |
| **핵심 기술** | Context Switching (문맥 교환) | 데이터 분할 및 하드웨어 분산 |
| **주요 관점** | **어떻게 효율적으로 관리할 것인가?** | **어떻게 빨리 끝낼 것인가?** |
| **예시** | 웹 브라우저에서 음악 들으며 타이핑하기 | 데이터베이스의 대량 데이터를 병렬로 쿼리 처리 |
