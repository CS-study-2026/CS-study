# **10-5.** Python 같은 언어는 CPython, Jython, PyPy등의 다양한 구현체가 있습니다. 각각은 어떤 차이가 있을까요? 또한, 실행되는 과정 또한 다를까요?

# 🐍 Python 구현체 (CPython / Jython / PyPy)

## 1️⃣ 개념 정의

Python은 하나의 언어지만,

👉 **여러 “구현체(Interpreter Implementation)”**가 존재한다.

즉,

- 문법은 동일

- 실행 엔진이 다름

---

# 2️⃣ 대표 Python 구현체 3가지

## 🟦 1) CPython (기본 구현)

### 📌 정의

- Python의 **표준 구현체**

- C 언어로 작성됨

- 우리가 보통 “Python”이라고 부르는 것

---

### 📌 실행 방식

```plain text
.py
 ↓
바이트코드(.pyc)
 ↓
CPython Virtual Machine 실행
```

---

### 📌 특징

- 가장 널리 사용

- C 확장 라이브러리 사용 가능

- 속도는 보통 수준

---

### 📌 단점

- GIL(Global Interpreter Lock) 존재

- 멀티스레드 성능 제한

---

## ☕ 2) Jython

### 📌 정의

👉 Python을 JVM 위에서 실행하는 구현체

---

### 📌 실행 방식

```plain text
.py
 ↓
Java Bytecode
 ↓
JVM 실행
```

---

### 📌 특징

- Java 라이브러리 사용 가능

- JVM 생태계 활용 가능

- Java 코드와 상호 운용성 높음

---

### 📌 단점

- CPython C 확장 사용 불가

- 최신 Python 기능 반영 느림

---

## ⚡ 3) PyPy

### 📌 정의

👉 JIT(Just-In-Time) 컴파일러 기반 Python 구현체

---

### 📌 실행 방식

```plain text
.py
 ↓
인터프리트 + JIT 컴파일
 ↓
실행 중 네이티브 코드 생성
```

---

### 📌 핵심 기술

- JIT 컴파일 (동적 최적화)

- 실행 중 자주 쓰는 코드 최적화

---

### 📌 특징

- 반복문, 연산 많은 코드에서 매우 빠름

- 실행 시간 최적화 강함

---

### 📌 단점

- 초기 실행 느림

- 메모리 사용량 증가

- C 확장 호환성 제한

---

# 3️⃣ 구현체 비교

| 구분 | CPython | Jython | PyPy |
| --- | --- | --- | --- |
| 기반 | C | Java (JVM) | Python 자체 + JIT |
| 실행 방식 | 바이트코드 인터프리터 | JVM 실행 | JIT 컴파일 |
| 속도 | 보통 | 느림~중간 | 빠름 (장기 실행) |
| 특징 | 표준 | Java 연동 | 성능 최적화 |
| GIL | 있음 | 없음 | 있음 (부분 개선) |

---

# 4️⃣ 실행 과정 차이 핵심

## 🟦 CPython

```plain text
Python 코드
→ Bytecode
→ Python VM 실행
```

---

## ☕ Jython

```plain text
Python 코드
→ Java Bytecode
→ JVM 실행
```

---

## ⚡ PyPy

```plain text
Python 코드
→ 인터프리터 실행 + JIT 분석
→ 최적화된 네이티브 코드 실행
```

---

# 5️⃣ 왜 구현체가 여러 개인가

## 1: 성능 최적화

- PyPy → 빠른 실행

## 2: 플랫폼 확장

- Jython → JVM 생태계 활용

## 3: 표준 유지

- CPython → 기본 호환성 유지

---

# 📌 핵심 요약

```javascript
- CPython: C 기반 표준 인터프리터
- Jython: JVM 위에서 실행되는 Python
- PyPy: JIT 기반 고성능 Python
- 각각 실행 방식과 최적화 전략이 다르다.
```
