# 18-5. 32비트에서, 페이지의 크기가 1KB 이라면 페이지 테이블의 최대 크기는 몇 개일까요?

## 0️⃣ **메모리 용량 단위 및 주소 공간**

### 저장 용량 단위

| 단위 | 값 (바이트 기준) | 2의 거듭제곱 |
| --- | --- | --- |
| Byte (B) | 1 B | 2^0 |
| KB | 1,024 B | 2^{10} |
| MB | 1,024 KB | 2^{20} B |
| GB | 1,024 MB | 2^{30} B |
| TB | 1,024 GB | 2^{40} B |

### 주소 공간

| 주소 비트 수 | 주소 공간 |
| --- | --- |
| 8비트 | 2^8 B = 256 B |
| 16비트 | 2^{16} B = 64 KB |
| 32비트 | 2^{32} B = 4 GB |
| 64비트 | 2^{64} B ≈ 16 EB |

## 1️⃣ 문제 접근

32비트 주소 공간 = `2³² Byte`

페이지 크기가 1KB = `2¹⁰ Byte`

---

## 2️⃣ 전체 페이지 개수 계산

공식

```plain text
전체 페이지 수

=

주소 공간 크기
────────────
페이지 크기
```

---

계산

```plain text
2³²
─────
2¹⁰

= 2²²
```

---

결과

```plain text
4,194,304 개
```

---

## 3️⃣ 의미

32비트 시스템에서
페이지 크기를 1KB로 사용하면

가상 주소 공간은
약 419만 개의 페이지로 분할된다.

---

## 4️⃣ 추가해설: 주소 구조 관점

> 페이지 번호 비트 수로 확인하기

논리 주소

```plain text
[ Page Number | Offset ]
```

---

페이지 크기

```plain text
1KB = 2¹⁰ Bytes
```

↓

Offset 표현 위해 `10bit` 필요

---

32bit 주소 공간

```plain text
남는 비트 공간

= 32 - 10

= 22bit
```

↓

Page Number

22bit

```plain text
[ Page Number | Offset ]

[    22bit   | 10bit ]
```

---

즉, 22 bit로 표현 가능한 번호 개수는

```plain text
2²²

=

4,194,304 Pages
```

---

## 📌 핵심 정리

- 32bit 주소 공간 = 4GB

- 페이지 크기 1KB = 2¹⁰

- 페이지 수 = 2²²

- 최대 페이지 개수 = 4,194,304개
