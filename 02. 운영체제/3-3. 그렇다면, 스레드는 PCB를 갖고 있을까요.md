# **3-3. 그렇다면, 스레드는 PCB를 갖고 있을까요?**

> 스레드를 가벼운 버전의 프로세스라고도 불리는데 그 이유는 프로세스와 비슷한 양상을 갖고 있기 때문입니다. 스레드는 프로세스가 PCB를 갖고 있는 것과 같이 TCB를 갖고 있습니다. TCB는 프로그램 카운터를 포함한 레지스터의 정보, 스택 포인터, 스레드 상태 등을 갖고 있습니다.

일반적으로 **스레드는 PCB를 갖지 않습니다.**

PCB(Process Control Block)는 **프로세스를 관리하기 위한 자료구조**이기 때문에 **프로세스 단위로 하나씩 존재**합니다.

반면 스레드는 **같은 프로세스 내부에서 실행되는 실행 흐름**이므로,

프로세스가 가진 **PCB를 공유**합니다.

대신 스레드는 **TCB(Thread Control Block)** 라는 별도의 자료구조를 가집니다.

---

### 스레드가 가지는 정보 (TCB)

각 스레드는 실행 상태를 관리하기 위해 다음과 같은 정보를 따로 가집니다.

- 프로그램 카운터 (Program Counter)

- CPU 레지스터

- 스택(Stack)

- 스레드 상태

- 스케줄링 정보

---

### 스레드가 공유하는 것

같은 프로세스에 속한 스레드들은 다음 자원을 **공유**합니다.

- Code 영역

- Data 영역

- Heap 영역

- 열린 파일

- 프로세스 자원

---

### 정리 (면접용 한 문장)

> 스레드는 PCB를 별도로 가지지 않고, 같은 프로세스의 PCB를 공유합니다. 대신 각 스레드는 자신의 실행 상태를 관리하기 위해 TCB와 스택, 레지스터 등을 개별적으로 가집니다.
