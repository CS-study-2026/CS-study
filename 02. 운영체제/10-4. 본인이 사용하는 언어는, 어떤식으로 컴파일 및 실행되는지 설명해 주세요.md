# **10-4.** 본인이 사용하는 언어는, 어떤식으로 컴파일 및 실행되는지 설명해 주세요.

# ☕ Java 컴파일 & 실행 과정

## 1️⃣ 개념 정의

Java는 **컴파일 언어 + 인터프리터 언어의 특징을 모두 가진 하이브리드 구조**이다.

👉 소스 코드(.java)가 바로 실행되지 않고

👉 **중간 단계인 바이트코드(.class)**로 변환된 뒤 실행된다.

---

# 2️⃣ 전체 실행 흐름

Java 프로그램의 실행 과정은 다음과 같다.

```plain text
.java (소스 코드)
   ↓  (javac 컴파일러)
.class (바이트코드)
   ↓  (JVM)
실행 결과
```

---

# 3️⃣ 단계별 상세 과정

## 1️⃣ 소스 코드 작성 (.java)

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

👉 사람이 작성하는 코드

---

## 2️⃣ 컴파일 단계 (javac)

```plain text
javac Main.java
```

### 📌 역할

- 소스 코드 문법 검사

- 바이트코드 생성

### 📌 결과

```plain text
Main.class 생성
```

👉 이 파일이 **JVM이 이해하는 코드**

---

## 3️⃣ 클래스 로딩 (Class Loader)

JVM 내부에서 실행 시작

### 📌 과정

- .class 파일을 메모리에 로드

- 필요한 클래스들을 동적으로 로딩

---

## 4️⃣ 바이트코드 검증 (Bytecode Verifier)

👉 보안 단계

- 잘못된 메모리 접근 검사

- 타입 안정성 검사

- JVM 규칙 위반 여부 확인

---

## 5️⃣ 실행 엔진 (Execution Engine)

### 📌 2가지 방식

### 1) 인터프리터 방식

- 바이트코드를 한 줄씩 실행

- 초기 실행 빠름

### 2) JIT 컴파일러 (Just-In-Time)

👉 자주 실행되는 코드 최적화

- 바이트코드를 네이티브 코드로 변환

- 성능 향상

---

# 4️⃣ JVM 구조

```plain text
JVM
 ├── Class Loader
 ├── Runtime Data Area
 ├── Execution Engine
 └── Native Interface
```

---

## 📌 Runtime Data Area

| 영역 | 설명 |
| --- | --- |
| Heap | 객체 저장 |
| Stack | 메서드 실행 |
| Method Area | 클래스 정보 |
| PC Register | 현재 실행 위치 |
| Native Stack | 네이티브 코드 실행 |

---

# 5️⃣ Java 특징 (컴파일 관점)

## 📌 플랫폼 독립성

👉 “Write Once, Run Anywhere”

- .class는 OS 독립적

- JVM만 있으면 어디서든 실행 가능

---

## 📌 C/C++와 비교

| 항목 | Java | C/C++ |
| --- | --- | --- |
| 컴파일 결과 | 바이트코드 | 머신코드 |
| 실행 방식 | JVM 필요 | 직접 실행 |
| 플랫폼 의존성 | 없음 | 있음 |

---

# 6️⃣ 실행 과정 핵심 요약

```plain text
1. .java 작성
2. javac로 .class 생성
3. Class Loader가 로드
4. Bytecode Verifier 검사
5. JVM 실행 (Interpreter + JIT)
```

---

# 7️⃣ 왜 이렇게 설계되었는가

## 📌 목적

- 보안성 강화

- 플랫폼 독립성 확보

- 메모리 관리 자동화

---

## 📌 핵심 의도

👉 “하드웨어가 아니라 JVM 위에서 실행되게 만들자”

---

# 📌 핵심 요약

- Java는 .java → .class → JVM 실행 구조

- JVM이 OS와 독립적으로 실행을 담당

- JIT 컴파일러로 성능 최적화

- Class Loader + Verifier + Execution Engine으로 구성
