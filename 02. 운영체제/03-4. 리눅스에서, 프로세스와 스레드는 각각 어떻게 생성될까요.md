# 3-4. 리눅스에서, 프로세스와 스레드는 각각 어떻게 생성될까요?

> 프레세스는 시스템 호출인 fork()를 통하여 생성이 됩니다. 또한 리눅스는 최초의 프로세스인 init을 갖고 있습니다. 
스레드는 프로세스와 비슷한 양상으로 시스템 호출인 pthread_create()를 사용하여 새로운 스레드를 생성합니다.

리눅스에서는 **프로세스와 스레드를 완전히 다른 개념으로 구현하지 않고**,

**같은 메커니즘을 기반으로 생성합니다.**

---

### 1️⃣ 프로세스 생성

리눅스에서 프로세스는 **`fork()`**** 시스템 호출**을 통해 생성됩니다.

- `fork()`는 **현재 프로세스를 복제하여 새로운 프로세스(자식 프로세스)를 생성**합니다.

- 부모 프로세스와 자식 프로세스는 **각각 독립적인 주소 공간**을 가집니다.

- 초기에는 **Copy-on-Write(COW)** 방식으로 메모리를 효율적으로 관리합니다.

```plain text
pid_tpid=fork();
```

- 부모 프로세스에는 **자식 프로세스의 PID**

- 자식 프로세스에는 **0**

이 반환됩니다.

---

### 2️⃣ 스레드 생성

리눅스에서는 스레드를 **`clone()`**** 시스템 호출**을 통해 생성합니다.

`clone()`은 어떤 자원을 공유할지 **옵션으로 지정**할 수 있습니다.

예를 들어 다음과 같은 옵션을 사용하면 스레드처럼 동작합니다.

- `CLONE_VM` : 메모리 공간 공유

- `CLONE_FILES` : 파일 디스크립터 공유

- `CLONE_SIGHAND` : 시그널 핸들러 공유

- `CLONE_THREAD` : 같은 스레드 그룹으로 생성

즉, 리눅스에서는

> **스레드를 "자원을 공유하는 경량 프로세스(Lightweight Process)" 형태로 구현합니다.**

---

### 3️⃣ 우리가 사용하는 스레드 생성 함수

일반적으로 C/C++에서는 다음 함수를 사용합니다.

```plain text
pthread_create()
```

하지만 내부적으로는 결국 **`clone()`**** 시스템 호출을 사용하여 스레드를 생성**합니다.

---

### 정리 (면접용)

> 리눅스에서 프로세스는 `fork()` 시스템 호출을 통해 생성되고, 스레드는 `clone()` 시스템 호출을 사용하여 생성됩니다. `clone()`은 메모리나 파일과 같은 자원의 공유 여부를 옵션으로 설정할 수 있으며, 이러한 자원 공유를 통해 스레드를 구현합니다.
