# 7-2. 왜 함수형 프로그래밍 매커니즘을 사용한다고 생각하시나요?

> **함수형 프로그래밍을 사용하는 주된 이유는 부수 효과를 줄여 코드의 동작을 예측하고, 검증하기 쉽게 만들기 위해서이다.**

예를 들어 두 함수를 비교

```java
// 외부 상태에 의존하고, 그 값을 변경
static int total = 0;

static int add(int amount) {
    total += amount;
    return total;
}
```

`add(100)`을 호출해도 기존 `total` 값에 따라 결과가 달라진다. 결과를 이해하려면 **앞에서 어떤 코드가 ****`total`****을 바꿨는지**도 확인해야 한다.

```java
// 입력으로 계산하고, 결과를 반환
static int add(int total, int amount) {
    return total + amount;
}
```

두 번째 함수는 `add(0, 100)`에 항상 `100`을 반환하고 외부 값을 바꾸지 않는다. 이런 **순수 함수와 불변성을 중심으로 코드를 구성**하면 다음과 같은 장점이 있다.

| 장점 | 이유 |
| --- | --- |
| 동작 예측이 쉬움 | 같은 입력에는 같은 결과가 나온다. |
| 테스트가 쉬움 | 외부 상태를 준비하지 않고 입력과 결과를 확인할 수 있다. |
| 오류 추적이 쉬움 | 다른 코드가 공유 값을 바꾸는 상황이 줄어든다. |
| 병렬 처리에 유리함 | 여러 작업이 같은 값을 수정하며 충돌할 가능성이 줄어든다. |

> 💡 실제 서비스에는 DB 저장이나 화면 출력 같은 부수 효과가 필요하다. 

따라서 **계산 로직은 순수 함수로 만들고, **

**필요한 부수 효과는 분리해서 관리하는 것**이 실용적인 사용 방법이다.
