# 3-1. 컴파일 할 때, static 키워드가 붙은 변수, 함수는 어떻게 처리되나요?

> Java 기준으로, **컴파일할 때 ****`static`**** 변수와 메서드가 실행되거나 메모리에 올라가는 것은 아니다.** 

### 예시 코드

```java
class Student {
    static int count = 5;
    static void printCount() {
        System.out.println(count);
    }
}
```

Java에서 컴파일러는 `count`와 `printCount()`를 객체가 아닌 `Student` 클래스에 속한 멤버로 확인하고, `.class` 파일에 `static` 속성을 기록한다. 컴파일할 때 `count`에 5를 대입하거나 메서드를 실행하지는 않는다. 프로그램 실행 중 JVM이 `Student` 클래스를 초기화할 때 `count`에 5를 대입한다. `printCount()`의 본문은 해당 메서드가 호출될 때 실행된다.
