# 3-2. Java에서 static과 static final은 어떤 차이를 갖나요? final과 static final은요?

>  **`static`****은 “누구의 값인가”**, `final`은 “다시 대입할 수 있는가”를 정한다.

| 선언 | 선언 위치 | 값의 소속 | 다시 대입 |
| --- | --- | --- | --- |
| `static int count` | 클래스 내부의 필드 | 클래스에 하나, 객체들이 공유 | 가능 |
| `final int id` | 클래스 내부의 인스턴스 필드 | 객체마다 각각 가짐 | 불가능 |
| `static final int MAX` | 클래스 내부의 필드 | 클래스에 하나, 객체들이 공유 | 불가능 |
| `final int number` | 메서드 내부의 지역변수 | 해당 메서드 실행에서 사용 | 불가능 |

### 예시 코드

```java
class Student {
    static int count = 0;
    final int id;
    static final int MAX_STUDENTS = 100;

    Student(int id) {
        this.id = id;  // 객체마다 생성될 때 한 번 지정
        count++;        // 학생을 만들 때마다 공유 값 변경
    }
}
```

학생 두 명을 만들면 `id`는 각 학생이 자기 값을 갖지만, `count`와 `MAX_STUDENTS`는 `Student` 클래스에 속한 값이다. 이 중 `count`는 바꿀 수 있고 `MAX_STUDENTS`는 다시 대입할 수 없다. 즉, `final`과 `static final`의 차이는 변경 가능 여부가 아니라** 객체별 값인지** **클래스 공통 값인지**이다. 전자는 객체마다 값을 갖고 후자는 클래스에 하나의 값을 갖는다.

참고로 객체를 가리키는 변수가 `final`이면 다른 객체로 다시 대입하는 것이 금지된다. 그 객체의 내부 상태까지 자동으로 불변이 되는 것은 아니다.
