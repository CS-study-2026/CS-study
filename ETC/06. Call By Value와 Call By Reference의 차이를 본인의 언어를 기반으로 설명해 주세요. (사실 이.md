# 6. Call By Value와 Call By Reference의 차이를 본인의 언어를 기반으로 설명해 주세요. (사실 이 질문에는 약간의 낚시가 있습니다. 과연 모든 언어에 저 개념이 존재할까요?)

# 6. Call By Value와 Call By Reference의 차이

## 1. Call By Value와 Call By Reference란?

함수를 호출할 때 인자(Argument)를 매개변수(Parameter)에 전달하는 방식을 의미한다.

두 방식의 핵심 차이는 **인자의 값을 복사해서 전달하는가, 호출자 변수 자체를 참조할 수 있도록 전달하는가**에 있다.

| 구분 | Call By Value | Call By Reference |
| --- | --- | --- |
| 전달 방식 | 인자의 값을 복사하여 전달 | 호출자 변수에 대한 참조를 전달 |
| 매개변수 | 독립적인 변수 | 호출자 변수의 별칭(Alias) |
| 매개변수 재할당 | 원본 변수에 영향 없음 | 원본 변수에 영향 있음 |
| 대표 언어 | Java | C++ |

## 2. Call By Value (값에 의한 호출)

함수를 호출할 때 **인자의 값을 복사하여 매개변수에 전달하는 방식**이다.

따라서 함수 내부에서 매개변수의 값을 변경하더라도 호출자 변수에는 영향을 주지 않는다.

```java
public class Main {
    public static void change(int num) {
        num = 100;
    }

    public static void main(String[] args) {
        int a = 10;
        change(a);

        System.out.println(a); // 10
    }
}
```

**동작 과정**

1. `a`에 10이 저장된다.

1. `change(a)`를 호출하면 값 10이 `num`에 복사된다.

1. `num = 100`으로 매개변수의 값을 변경한다.

1. `a`와 `num`은 독립적인 변수이므로 `a`는 여전히 10이다.

## 3. Call By Reference (참조에 의한 호출)

함수를 호출할 때 **호출자 변수에 대한 참조를 전달하는 방식**이다.

매개변수가 호출자 변수의 별칭처럼 동작하므로, 함수 내부에서 매개변수를 변경하면 원본 변수도 변경된다.

Java는 Call By Reference를 지원하지 않으므로 C++ 예제로 살펴보자.

```c++
#include <iostream>
using namespace std;

void change(int& num) { 
    num = 100;
}

int main() {
    int a = 10;
    change(a);

    cout << a; // 100
}
```

**동작 과정**

1. `a`에 10이 저장된다.

1. `change(a)`를 호출하면 `num`이 `a`의 참조로 연결된다.

1. `num = 100`을 실행하면 실제로 `a`의 값이 변경된다.

1. 따라서 `a`를 출력하면 100이 나온다.

## 4. Java는 Call By Value일까, Call By Reference일까?

**Java는 기본형과 참조형 모두 Call By Value만 사용한다.**

다만 참조형 객체를 전달할 때 Call By Reference와 혼동하기 쉽다.

### 4-1. 기본형 (Primitive Type)

```plain text
void change(int num) {
    num = 100;
}
```

`int`, `double`, `boolean` 등의 기본형은 실제 값이 복사된다.

따라서 메서드 내부에서 값을 변경해도 원본 변수는 영향을 받지 않는다.

### 4-2. 참조형 (Reference Type)

```plain text
class Person {
    String name;

    Person(String name) {
        this.name = name;
    }
}

public class Main {
    static void change(Person p) {
        p.name = "Kim";
    }

    public static void main(String[] args) {
        Person person = new Person("Lee");
        change(person);

        System.out.println(person.name); // Kim
    }
}
```

객체의 필드가 변경되었으므로 Call By Reference처럼 보일 수 있다.

하지만 실제로는 **객체를 가리키는 참조값이 복사되어 전달된 것**이다.

**동작 과정**

1. `person`은 `Person("Lee")` 객체를 참조한다.

1. `change(person)`을 호출하면 참조값이 `p`에 복사된다.

1. `person`과 `p`는 서로 다른 참조 변수지만 동일한 객체를 가리킨다.

1. `p.name = "Kim"`은 해당 객체의 필드를 수정한다.

1. 따라서 `person.name`도 `"Kim"`으로 출력된다.

반면 매개변수에 다른 객체를 대입하면 결과가 달라진다.

```plain text
static void change(Person p) {
    p = new Person("Kim");
}

public static void main(String[] args) {
    Person person = new Person("Lee");
    change(person);

    System.out.println(person.name); // Lee
}
```

`p`에 새로운 객체를 대입하더라도 `person`이 가리키는 객체는 변경되지 않는다.

이는 Java가 Call By Reference가 아니라 **Call By Value를 사용한다는 중요한 근거**다.

## 5. 질문 속 낚시: 모든 언어가 두 방식을 지원할까?

**아니다. 모든 프로그래밍 언어가 Call By Value와 Call By Reference를 모두 지원하는 것은 아니다.**

| 언어 | 인자 전달 방식 |
| --- | --- |
| Java | Call By Value |
| C | Call By Value (포인터값 전달 가능) |
| C++ | Call By Value, Call By Reference |
| Python | Call by Sharing |
| JavaScript | Call By Value (객체 참조값 복사) |

### Java

- Call By Value만 지원한다.

- 참조형 객체도 참조값을 복사하여 전달한다.

### C

- Call By Value만 지원한다.

- 포인터를 전달하여 원본 데이터에 접근할 수 있지만, 포인터 자체도 값이 복사되어 전달된다.

### C++

- Call By Value와 Call By Reference를 모두 지원한다.

- `int& num`처럼 참조 매개변수를 선언할 수 있다.

### Python

- 일반적으로 Call by Sharing(객체 공유에 의한 전달)으로 설명한다.

- 호출자와 함수의 매개변수가 동일한 객체를 참조할 수 있다.

- 매개변수에 새로운 객체를 대입해도 호출자의 변수에는 영향을 주지 않는다.

## 6. 면접 답변 정리

Call By Value는 인자의 값을 복사해서 전달하는 방식이고, Call By Reference는 호출자 변수에 대한 참조를 전달하여 함수 내부에서 원본 변수를 변경할 수 있는 방식입니다.

제가 사용하는 Java는 Call By Value만 지원합니다. 기본형은 실제 값이 복사되고, 참조형은 객체를 가리키는 참조값이 복사됩니다. 따라서 메서드 내부에서 객체의 상태를 변경할 수 있지만, 매개변수에 다른 객체를 대입하더라도 호출자의 참조 변수에는 영향을 주지 않습니다.

또한 모든 언어가 두 방식을 모두 지원하는 것은 아닙니다. C++은 두 방식을 지원하지만 Java는 Call By Value만 지원하고, Python은 Call by Sharing이라는 개념으로 설명할 수 있습니다.

**핵심 정리**

- Call By Value: 값 복사

- Call By Reference: 호출자 변수에 대한 참조 전달

- Java: 기본형과 참조형 모두 Call By Value

- 객체의 상태를 변경할 수 있다는 사실만으로 Call By Reference라고 판단해서는 안 된다.
