# 7-4. 고차함수에 대해 설명해주세요.

## 면접 답변

> 고차함수는 **함수를 인자로 받거나 함수를 반환하는 함수**입니다. 
자바에서는 함수형 인터페이스와 람다, 메서드 참조를 이용해 표현
Stream의 map과 filter가 대표적인 예이며, 공통 처리 흐름과 구체적인 동작을 분리하여 재사용성과 조합성을 높일 수 있습니다.

---

## 1. 고차함수란?

다음 두 조건 중 하나 이상을 만족하면 고차함수(Higher-Order Function)입니다.

- 함수를 인자로 받는다.

- 함수를 반환한다.

일반적인 함수에 숫자나 문자열 같은 데이터를 전달한다면, 고차함수에는 ‘어떤 작업을 할지’도 전달할 수 O

자바에서는 함수 자체를 독립적인 함수 타입으로 전달하기보다, 
동작을 나타내는 함수형 인터페이스 타입의 값으로 전달함. 람다 표현식이나 메서드 참조로 그 동작을 구현할 수 O

---

## 2. 함수를 인자로 받는 예시

‘전달받은 작업을 두 번 적용한다’는 공통 흐름

```java
import java.util.function.Function;

public class HigherOrderExample {
    static int applyTwice(int value,
                          Function<Integer, Integer> operation) {
        return operation.apply(operation.apply(value));
    }

    public static void main(String[] args) {
        int a = applyTwice(3, x -> x + 1);
        int b = applyTwice(3, x -> x * 2);

        System.out.println(a); // 5: 3 → 4 → 5
        System.out.println(b); // 12: 3 → 6 → 12
    }
}
```

**흐름: 입력 3 → operation(3) = 4 → operation(4) = 5**

- applyTwice(): **함수를 전달받으므로 고차함수**입니다.

- x -> x + 1: **전달할 동작을 작성한 람다 표현식**입니다.

- operation.apply(value): 전달받은 동작을 실행합니다.

Function<T, R>은 T 타입의 입력을 받아 R 타입의 결과를 반환하는 동작을 표현합니다. 
Function<Integer, Integer>는 정수를 받아 정수를 반환한다는 뜻

---

## 3. 함수를 반환하는 예시

multiplier()는 ‘몇 배를 할지’를 받아, 해당 배수를 곱하는 동작을 반환합니다.

```java
import java.util.function.Function;

public class FunctionFactoryExample {
    static Function<Integer, Integer> multiplier(int factor) {
        return x -> x * factor;
    }

    public static void main(String[] args) {
        Function<Integer, Integer> times3 = multiplier(3);
        Function<Integer, Integer> times5 = multiplier(5);

        System.out.println(times3.apply(4)); // 12
        System.out.println(times5.apply(4)); // 20
    }
}
```

multiplier(3)은 계산 결과 12가 아니라 ‘입력값에 3을 곱하는 동작’을 반환합니다. 
이후 times3.apply(4)를 호출해야 12가 계산됩니다. 
반환된 람다는 바깥 메서드의 factor 값을 캡처합니다. 
이 예제의 factor는 변경되지 않는 기본형 값입니다.

## 4. 실무에서 자주 만나는 예: Stream

```java
import java.util.List;

public class StreamExample {
    public static void main(String[] args) {
        List<Integer> result = List.of(1, 2, 3, 4).stream()
                .filter(x -> x % 2 == 0)
                .map(x -> x * x)
                .toList();

        System.out.println(result); // [4, 16]
    }
}
```

**[1, 2, 3, 4] → filter(짝수인가?) → [2, 4] → map(제곱하기) → [4, 16]**

filter()는 조건을 판별하는 Predicate를, map()은 값을 변환하는 Function을 받습니다. 
두 메서드 모두 동작을 인자로 받으므로 고차함수입니다.

---

## 5. 자주 사용하는 함수형 인터페이스

| 인터페이스 | 동작 | 실행 메서드 | 예시 |
| --- | --- | --- | --- |
| Function<T, R> | T → R 변환 | apply(T) | x → x * x |
| Predicate<T> | T → boolean 판별 | test(T) | x → x > 0 |
| Consumer<T> | T를 받아 처리, 반환값 없음 | accept(T) | System.out::println |
| Supplier<T> | 입력 없이 T 제공 | get() | () → "hello" |

---

## 6. 순수함수·람다와의 차이

- **고차함수:** 함수를 받거나 반환하는지에 대한 개념

- **순수함수:** 같은 입력에 같은 결과를 반환하고, 관찰 가능한 부수효과가 없는지에 대한 개념

- **람다:** 이름 없이 동작을 작성하는 표현식입니다. 람다라고 해서 반드시 순수함수 또는 고차함수인 것은 X

고차함수에 전달한 람다가 공유 상태를 수정하면 여전히 동시성 문제가 발생할 수 있습니다. Stream에 전달하는 동작은 일반적으로 상태에 의존하지 않고 데이터 소스를 변경하지 않도록 작성해야 합니다.

## 7. 예상 꼬리 질문

- **왜 사용하나요?** 
→ 반복되는 제어 흐름과 변경되는 동작을 분리해 중복을 줄이고 여러 동작을 조합하기 위해 사용합니다.

- **람다와 고차함수는 같은 건가요?
→ X. **람다는 동작을 표현하는 문법이고, 고차함수는 동작을 받거나 반환하는 함수의 성질입니다.

- **고차함수는 항상 순수한가요?** 
→ X. 전달받은 동작이나 고차함수 자체가 외부 상태를 읽거나 변경할 수 있습니다.
