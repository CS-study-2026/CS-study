# 3-0. static 키워드는 어떤 의미를 갖나요?

## 1. 클래스와 객체

`Student` 클래스는 학생을 만들기 위한 설계도이고, `a`와 `b`는 그 설계도로 만든 서로 다른 객체이다.

```java
class Student {
    String name;
}

Student a = new Student();
Student b = new Student();

a.name = "민수";
b.name = "지연";
```

`a.name`은 민수, `b.name`은 지연이다. `name`은 **학생마다 따로 가지는 값**이기 때문이다.

## 2. 자바의 `static`은 무엇인가요?

자바에서 필드나 메서드 앞에 `static`을 붙이면 **개별 객체가 아니라 클래스에 속한다**는 뜻이다.

```java
class Student {
    String name;               // 객체마다 따로 있음
    static int studentCount;    // Student 클래스에 하나 있음

    Student(String name) {
        this.name = name;
        studentCount++;
    }
}
```

```java
Student a = new Student("민수");
Student b = new Student("지연");

System.out.println(a.name);               // 민수
System.out.println(b.name);               // 지연
System.out.println(Student.studentCount); // 2
```

학생의 `name`은 각 객체에 따로 있다. `studentCount`는 모든 학생을 합쳐 세는 값이므로 클래스에 **하나만** 있다. 그래서 `Student.studentCount`처럼 클래스 이름으로 접근한다.

| 선언 | 누구의 것인가요? | 접근 예시 |
| --- | --- | --- |
| `String name` | 학생 객체 각각 | `a.name` |
| `static int studentCount` | `Student` 클래스 | `Student.studentCount` |

## 3. 메서드에 `static`을 붙이면요?

**객체를 만들지 않아도 호출할 수 있는 메서드**가 됩니다.

```java
class Calculator {
    static int add(int a, int b) {
        return a + b;
    }
}

int result = Calculator.add(2, 3); // 5
```

덧셈에는 특정 `Calculator` 객체의 상태가 필요하지 않다. 그래서 `new Calculator()` 없이 `Calculator.add(...)`로 호출할 수 있다.

반대로 정적 메서드에서는 객체의 필드를 **그냥 이름만 써서** 읽을 수 없다.

```java
class Student {
    String name;

    static void printName() {
        // System.out.println(name); // 오류
    }
}
```

`Student.printName()`을 호출했을 때 민수의 `name`을 출력할지, 지연의 `name`을 출력할지 정해져 있지 않기 때문이다. 이 점이 핵심!

<details>
<summary>해결 방법</summary>

```java
//특정 학생 객체를 지정
class Student {
    String name;

    static void printName(Student student) {
        System.out.println(student.name);
    }

    public static void main(String[] args) {
        Student a = new Student();
        a.name = "민수";

        Student.printName(a); // 민수
    }
}
```
</details>

## 4. 파이썬에서는요?

파이썬에는 자바의 `static` **키워드**가 없다. 비슷한 용도의 정적 메서드를 만들 때 `@staticmethod`를 쓴다.

```python
class Calculator:    
	@staticmethod    
	def add(a, b):        
		return a + b
		
print(Calculator.add(2, 3))  # 5
```

이 메서드는 호출한 객체를 나타내는 `self`를 자동으로 받지 않는다. `cls`도 받지 않는다. 두 숫자만 전달받아 계산한다.

파이썬에서 클래스가 공유하는 값을 정의할 때는 클래스 안에 변수를 적는다.

```python
class Student:    
	school = "한국학교"  # 클래스 변수
	
print(Student.school)  # 한국학교
```

이때는 `@staticmethod`를 변수에 붙이지 않는다. **파이썬의 ****`@staticmethod`****는 메서드에 쓰는 것**이다.

---

### 자바와 파이썬의 static 비교

**자바에서 ****`static`****은 필드나 메서드가 개별 객체가 아닌 클래스에 속한다는 뜻**이다. 다만 자바에는 `static` **키워드**가 있고, 파이썬에는 같은 키워드 대신 `@staticmethod` **데코레이터**가 있다.

| 구분 | 자바 | 파이썬 |
| --- | --- | --- |
| 정적 메서드 | `static`을 붙임 | `@staticmethod`를 붙임 |
| 호출 | `클래스명.메서드()` | `클래스명.메서드()` |
| 객체 정보 | `this`가 없어 객체의 필드에 직접 접근할 수 없음 | `self`가 자동으로 전달되지 않음 |
| 공유 변수 | `static` 필드로 선언 | 클래스 본문에 변수를 정의 |

### Java

```java
class Calculator {
    static int add(int a, int b) {
        return a + b;
    }
}

Calculator.add(2, 3);  // 5
```

### Python

```python
class Calculator:
    @staticmethod
    def add(a, b):
        return a + b

Calculator.add(2, 3)  # 5
```

두 `add` 모두 특정 객체의 상태가 필요 없어서 객체 생성 없이 호출한다. 자바의 `static` 필드는 객체들이 **하나를 공유**한다는 의미도 있다. 파이썬에서는 클래스 본문에 정의한 변수가 이에 가깝지만, 객체에 같은 이름의 속성을 따로 만들 수 있어 동작이 완전히 같지는 않다.

참고로 파이썬에서 **클래스 자체를 ****`cls`****로 받아 사용**하려면 `@staticmethod`가 아니라 `@classmethod`를 쓴다.

> 💡 

### `main` 메서드가 왜 `static`인지

```java
public static void main(String[] args) {
    // 프로그램 시작 지점
}
```

프로그램이 시작될 때는 아직 `Main` 객체를 만들지 않았다. 따라서 JVM이 객체 생성 없이 `Main.main(...)`을 호출할 수 있도록 `static`으로 선언한다.
