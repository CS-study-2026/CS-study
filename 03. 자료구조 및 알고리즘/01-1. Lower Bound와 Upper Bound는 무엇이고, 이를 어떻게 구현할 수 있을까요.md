# 1-1. Lower Bound와 Upper Bound는 무엇이고, 이를 어떻게 구현할 수 있을까요?

## 1-1. Lower Bound와 Upper Bound의 정의

두 개념 모두 정렬된 상태를 유지하면서 특정 값 k를 삽입할 수 있는 위치를 찾는 것이 목적이다.

### ① Lower Bound (하한)

- **정의:** 찾고자 하는 값 target 이상의 값이 처음으로 나타나는 위치를 의미한다.

- **핵심:** arr[idx] \ge target인 가장 작은 idx를 찾는다.

### ② Upper Bound (상한)

- **정의:** 찾고자 하는 값 target을 초과하는 값이 처음으로 나타나는 위치를 의미한다.

- **핵심:** arr[idx] > target인 가장 작은 idx를 찾는다.

---

## 1-2. 파라메트릭 서치 (Parametric Search)

### 1. 정의 및 핵심 아이디어

- **최적화 문제:** "조건을 만족하는 x의 최댓값은 무엇인가?"

- **결정 문제:** "특정 값 x일 때 조건을 만족하는가? (Yes/No)"

이진 탐색을 이용해 특정 값 x를 계속 던지며 결정 함수(Check function)를 호출하고, 그 결과에 따라 탐색 범위를 좁혀나가면서 최종적인 최적값을 찾아내는 방식이다.

---

### 2. 파라메트릭 서치 vs 이진 탐색

| **구분** | **이진 탐색 (Binary Search)** | **파라메트릭 서치 (Parametric Search)** |
| --- | --- | --- |
| **목표** | 정렬된 배열에서 특정 **값** 찾기 | 조건 만족하는 **최적의 값(경계선)** 찾기 |
| **대상** | 배열 인덱스 | 문제에서 요구하는 **해(Solution)의 범위** |
| **판단 기준** | `arr[mid]`와 `target` 비교 | **결정 함수 ****`check(mid)`**의 리턴값 |

---

## 2. 구현 방식: 이진 탐색의 응용

두 알고리즘 모두 이진 탐색을 기반으로 하므로 **시간 복잡도는 ****O(\log N)**이다. 일반적인 이진 탐색은 값을 찾으면 즉시 종료하지만, Bound 알고리즘은 **조건을 만족하는 가장 왼쪽(혹은 오른쪽) 위치를 끝까지 탐색**한다.

### ① Lower Bound 구현 로직

값 k가 배열에 여러 개 있을 때, 가장 왼쪽에 있는 k의 인덱스를 반환해야 한다.

1. `mid` 위치의 값이 `target`보다 **크거나 같으면**, `high`를 `mid`로 줄여 더 왼쪽을 탐색한다.

1. `mid` 위치의 값이 `target`보다 **작으면**, `low`를 `mid + 1`로 높인다.

### ② Upper Bound 구현 로직

값 k보다 큰 값이 처음 나오는 위치를 찾아야 한다.

1. `mid` 위치의 값이 `target`보다 **크면**, `high`를 `mid`로 줄인다.

1. `mid` 위치의 값이 `target`보다 **작거나 같으면**, `low`를 `mid + 1`로 높여 더 오른쪽을 탐색한다.

---

## 3. Java 구현 예시

```java
// Lower Bound: target 이상의 값이 처음 나오는 인덱스
public static int lowerBound(int[] arr, int target) {
    int low = 0;
    int high = arr.length; // 배열 끝 다음 위치까지 고려
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] >= target) {
            high = mid;
        } else {
            low = mid + 1;
        }
    }
    return low;
}

// Upper Bound: target을 초과하는 값이 처음 나오는 인덱스
public static int upperBound(int[] arr, int target) {
    int low = 0;
    int high = arr.length;
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] > target) {
            high = mid;
        } else {
            low = mid + 1;
        }
    }
    return low;
}
```

## 4. 실전 활용 사례

### ① 중복 원소의 개수 구하기

정렬된 배열에서 특정 값 target이 몇 개 존재하는지 구할 때 유용하다.

- **공식:** `upperBound(target) - lowerBound(target)`

- 예: `[1, 2, 2, 2, 3]`에서 `2`의 개수는 `upper(index 4) - lower(index 1) = 3`이다.

### ② 특정 범위 내의 숫자 개수 구하기

`[L, R]` 범위에 속하는 숫자의 개수를 구할 때 사용한다.

- **공식:** `upperBound(R) - lowerBound(L)`
