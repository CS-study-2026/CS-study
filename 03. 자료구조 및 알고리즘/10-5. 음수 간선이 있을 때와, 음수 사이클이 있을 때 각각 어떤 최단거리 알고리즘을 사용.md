# **10-5.** 음수 간선이 있을 때와, 음수 사이클이 있을 때 각각 어떤 최단거리 알고리즘을 사용해야 하는지 설명해 주세요.

# 1. 음수 간선(negative edge)이 있는 경우

## 개념

음수 간선이란 **가중치가 0보다 작은 간선**을 의미한다.

예시

```plain text
A → B : 4
A → C : 5
C → B : -10
```

이 경우

```plain text
A → B = 4
A → C → B = 5 + (-10) = -5
```

따라서 **직접 가는 경로보다 더 짧은 경로가 나중에 발견될 수 있다.**

---

## 다익스트라 알고리즘을 사용할 수 없는 이유

다익스트라는 다음 **Greedy 가정**을 기반으로 동작한다.

> 현재 가장 짧은 거리로 선택된 정점의 거리는 이후에도 더 줄어들지 않는다.

하지만 음수 간선이 존재하면

```plain text
이미 확정된 거리보다 더 짧은 경로가 나중에 발견될 수 있다.
```

따라서 **다익스트라는 음수 간선이 있는 그래프에서는 올바른 결과를 보장하지 않는다.**

---

## 사용 알고리즘: Bellman-Ford

음수 간선이 있지만 **음수 사이클이 없는 경우**에는 **Bellman-Ford 알고리즘**을 사용한다.

### 특징

- 음수 간선 허용

- 단일 시작점 최단거리(Single Source Shortest Path) 계산

- 모든 간선을 반복적으로 완화(relaxation)

### 알고리즘 원리

정점이 `V`개일 때

- 최단 경로는 **최대 V-1개의 간선**을 가진다.

- 따라서 모든 간선을 **V-1번 반복 완화**하면 최단거리가 계산된다.

### 시간 복잡도

```plain text
O(VE)
```

---

# 2. 음수 사이클(negative cycle)이 있는 경우

## 개념

음수 사이클이란 **사이클을 한 바퀴 돌았을 때 총 가중치가 음수인 경우**이다.

예시

```plain text
A → B : 2
B → C : -5
C → B : 1
```

사이클

```plain text
B → C → B
```

가중치 합

```plain text
-5 + 1 = -4
```

즉 **한 번 돌 때마다 경로 비용이 계속 감소한다.**

---

## 문제점

음수 사이클이 존재하면 다음과 같은 일이 발생한다.

```plain text
사이클을 계속 돌면서 경로 비용을 무한히 줄일 수 있음
```

따라서

```plain text
최단거리 = -∞
```

가 되어 **최단거리 자체가 정의되지 않는다.**

---

# 3. 음수 사이클 탐지

음수 사이클이 존재하는지 확인할 때도 **Bellman-Ford 알고리즘**을 사용한다.

### 방법

1. 모든 간선을 `V-1`번 완화

1. **한 번 더 완화 시도**

만약 이때도 값이 갱신된다면

```plain text
음수 사이클 존재
```

이유

- 정상적인 그래프라면 `V-1`번 이후에는 더 이상 거리 갱신이 발생하지 않는다.

- 갱신이 발생한다는 것은 **음수 사이클을 통해 계속 감소하고 있다는 의미**이다.

---

# 4. 모든 정점 쌍 최단거리 (Floyd-Warshall)

모든 정점 쌍의 최단거리를 구할 때는 **Floyd-Warshall 알고리즘**을 사용할 수 있다.

### 특징

- 음수 간선 허용

- 음수 사이클 탐지 가능

### 음수 사이클 판단

```plain text
dist[i][i] < 0
```

이면 **i 정점이 포함된 음수 사이클 존재**

---

# 5. 알고리즘 선택 기준 정리

| 상황 | 사용 알고리즘 |
| --- | --- |
| 모든 간선이 양수 | Dijkstra |
| 음수 간선 존재 (음수 사이클 없음) | Bellman-Ford |
| 음수 사이클 존재 여부 판단 | Bellman-Ford |
| 모든 정점 쌍 최단거리 | Floyd-Warshall |

---

# 6. 핵심 정리

- **음수 간선 O, 음수 사이클 X**

→ **Bellman-Ford 사용**

- **음수 사이클 O**

→ **최단거리 정의 불가**, Bellman-Ford로 **음수 사이클 탐지**

- **모든 정점 쌍 최단거리**

→ **Floyd-Warshall 사용**
