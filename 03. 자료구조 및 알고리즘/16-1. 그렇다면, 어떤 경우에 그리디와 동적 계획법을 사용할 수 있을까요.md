# **16-1.** 그렇다면, 어떤 경우에 그리디와 동적 계획법을 사용할 수 있을까요?

# **그리디 vs 동적계획법(DP) 사용 기준 비교**

## **1️⃣ 핵심 차이 한눈에 보기**

| **구분** | **그리디 (Greedy)** | **동적계획법 (DP)** |
| --- | --- | --- |
| 선택 방식 | 매 순간 **최선의 선택** | 모든 경우를 고려한 최적해 저장 |
| 미래 고려 | ❌ 미래 고려 안 함 | ⭕ 이전 결과 활용 |
| 최적해 보장 | 조건 만족 시만 가능 | 항상 가능 (정의상) |
| 구현 난이도 | 비교적 쉬움 | 상대적으로 복잡 |
| 시간복잡도 | 보통 O(N)~O(N log N) | 보통 O(N²) 또는 O(N×상태수) |

---

# **2️⃣ 언제 그리디를 쓰는가?**

## **✔ 사용 조건**

### **1. Greedy Choice Property**

> 현재의 최선 선택이 전체 최적해로 이어짐

### **2. Optimal Substructure**

> 부분 문제의 최적해가 전체 문제의 일부가 됨

---

## **✔ 직관적 판단 기준**

```plain text
"지금 가장 좋아 보이는 선택을 해도 나중에 후회하지 않을까?"
```

→ 후회하지 않는 구조라면 **그리디**

---

## **✔ 대표 예시**

- 거스름돈 문제 (동전 단위가 1,5,10,50 등)

- 최소 신장 트리 (Kruskal, Prim)

- 회의실 배정

---

# **3️⃣ 언제 동적계획법(DP)을 쓰는가?**

## **✔ 사용 조건**

### **1. Optimal Substructure**

- 큰 문제 = 작은 문제의 최적해 조합

### **2. Overlapping Subproblems**

- 같은 부분 문제가 여러 번 반복됨

---

## **✔ 직관적 판단 기준**

```plain text
"한 번 계산한 걸 또 계산하고 있지 않나?"
```

→ 반복 계산 발생 → DP

---

## **✔ 대표 예시**

- 피보나치 수열

- 배낭 문제 (Knapsack)

- LIS (최장 증가 부분 수열)

- 최단 거리 (Bellman-Ford)

---

# **4️⃣ 핵심 차이 직관 비교**

## **예시: 동전 문제**

### **동전: 1, 3, 4**

목표: 6

### **그리디**

- 4 → 1 → 1 → 총 3개

### **최적해**

- 3 → 3 → 총 2개

👉 그리디 실패 → DP 필요

---

# **5️⃣ 판단 흐름 정리**

```plain text
1. 그리디로 풀어도 항상 최적해가 나오는가?
   → YES → 그리디

2. 아니라면?
   → DP 고려

3. 같은 부분 문제가 반복되는가?
   → YES → DP
```

---

# **6️⃣ 시간복잡도 관점 차이**

- 그리디 → 선택 후 돌아가지 않음

- DP → 상태를 저장하며 탐색

DP는 보통 **시간과 공간을 교환**하는 방식

# **🎯 한 줄 정리**

> 그리디는 현재의 최선 선택이 전체 최적해를 보장할 때 사용하고,
그렇지 않고 부분 문제가 반복된다면 동적계획법을 사용한다.
