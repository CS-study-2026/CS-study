# **9-1.** 각 방법에 대해, "두 정점이 연결되었는지" 확인하는 시간복잡도와 "한 정점에 연결된 모든 정점을 찾는" 시간복잡도, 그리고 공간복잡도를 비교해 주세요.

# 1. 두 정점 연결 확인

- 인접 행렬 : O(1)

  - 생성된 2차원 배열의 값을 즉시 참조하므로  O(1)으로 확인 가능하다.



- 인접 리스트 : O(V)

  - 특정 노드의 리스트를 처음부터 끝까지 훑으며 원하는 노드가 있는지 찾아야 하므로, 리스트의 길이에 비례하는 시간이 걸린다.

# 2. 연결된 모든 정점 찾기

- 인접 행렬 : O(V)

  - 연결 여부와 상관없이 행 전체(V개 열)를 모두 검사해야 하므로 항상 O(V)가 소요된다.

- 인접 리스트 : O(Degree(V))

  - 자신과 실제로 연결된 노드들만 담겨 있는 리스트만 확인하면 되므로, 해당 노드의 차수(Degree)만큼만 시간이 걸려 훨씬 빠르다.

# 3. 공간 복잡도

- 인접 행렬 : O(V^2)

  - 노드 수(V)의 제곱에 비례하는 2차원 배열을 생성하여 간선(E)이 적더라도 항상 V \times V 크기의 공간을 차지한다.


- 인접 리스트 : O(V+E)

  - 노드 수와 실제 존재하는 간선의 수 만큼만 메모리를 할당하므로, 간선이 적은 희소 그래프(Sparse Graph)에서 압도적으로 효율적이다.
