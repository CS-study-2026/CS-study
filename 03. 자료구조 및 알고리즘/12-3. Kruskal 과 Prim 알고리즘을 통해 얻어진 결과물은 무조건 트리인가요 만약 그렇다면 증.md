# **12-3.** Kruskal 과 Prim 알고리즘을 통해 얻어진 결과물은 무조건 트리인가요? 만약 그렇다면 증명해 주세요. 그렇지 않다면, 반례를 설명해 주세요.

# Kruskal & Prim 알고리즘의 결과는 항상 트리인가?

## ✅ 결론

- 입력 그래프가 **연결 그래프**라면 → 결과는 항상 **트리**

- 입력 그래프가 **비연결 그래프**라면 → 결과는 **최소 신장 포레스트**

---

# 1. 트리(Tree)의 정의

정점이 n개인 그래프가 트리가 되려면 다음 조건을 만족한다.

1. 연결되어 있다.

1. 사이클이 없다.

1. 간선 수가 정확히 n-1개이다.

위 조건들은 서로 동치이다.

즉,

- 연결 + 사이클 없음 ⇔ 간선 수 = n-1

---

# 2. Kruskal 알고리즘

## 🔹 알고리즘 요약

1. 모든 간선을 가중치 오름차순으로 정렬

1. 사이클을 만들지 않는 간선만 선택

1. 간선이 n-1개가 되면 종료

(Union-Find 사용)

---

## 🔹 트리임을 증명

### ① 사이클이 없다

- 간선을 추가하기 전에 두 정점이 이미 연결되어 있는지 검사

- 이미 연결되어 있다면 그 간선은 버림

따라서 결과 그래프에는 사이클이 존재할 수 없다.

---

### ② 간선 수 = n-1

초기 상태

- 정점: n개

- 컴포넌트: n개

간선 하나 추가할 때마다

- 서로 다른 두 컴포넌트를 합침

- 컴포넌트 수가 정확히 1 감소

병합 과정

- 처음: n개

- 간선 1개 추가 → n-1개

- 간선 2개 추가 → n-2개

- ...

- 간선 n-1개 추가 → 1개

따라서 선택된 간선 수는 정확히 n-1개

---

### ③ 연결성

입력 그래프가 연결 그래프라면

모든 정점이 하나의 컴포넌트가 된다.

---

### ✅ 결론 (Kruskal)

- 사이클 없음

- 간선 수 n-1

- 연결됨

→ 트리

---

# 3. Prim 알고리즘

## 🔹 알고리즘 요약

1. 임의의 정점에서 시작

1. 현재 트리 집합 S와 외부 정점을 연결하는 최소 간선 선택

1. 정점을 하나씩 확장

---

## 🔹 트리임을 증명

### ① 사이클이 없다

- 항상 "트리에 포함된 정점"과

"아직 포함되지 않은 정점"을 연결하는 간선만 선택

- 이미 트리 안에 있는 정점끼리는 연결하지 않음

따라서 사이클이 생길 수 없다.

---

### ② 연결성

- 그래프가 연결 그래프라면

- 시작 정점에서 확장해 나가며 결국 모든 정점을 포함

따라서 모든 정점이 하나의 연결 구조가 된다.

---

### ③ 간선 수

- 시작 정점 제외

- 정점 하나 추가할 때마다 간선 1개 추가

총 간선 수 = n-1

---

### ✅ 결론 (Prim)

- 사이클 없음

- 연결성 확보

- 간선 수 n-1

→ 트리

---

# 4. 알고리즘 비교

| 항목 | Kruskal | Prim |
| --- | --- | --- |
| 기준 | 간선 중심 | 정점 중심 |
| 사이클 방지 | 명시적으로 검사 | 구조적으로 발생 불가 |
| 간선 수 | n-1개 | n-1개 |
| 연결 그래프일 때 결과 | 트리 | 트리 |

---

# 5. 비연결 그래프의 경우

예시

A — B

C — D

- Kruskal → 두 개의 트리 생성

- Prim → 시작한 연결 요소만 확장

결과는 하나의 트리가 아니라

**최소 신장 포레스트**

---

# 🎯 최종 정리

✔ 연결 그래프 → 항상 트리

✔ 비연결 그래프 → 최소 신장 포레스트
