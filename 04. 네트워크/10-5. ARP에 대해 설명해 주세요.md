# 10-5. ARP에 대해 설명해 주세요.

# 1. ARP(Address Resolution Protocol)

1. ARP란?

> Note 네트워크 상에서 논리적 주소인 'IP 주소(L3)'를 물리적 주소인 'MAC 주소(L2)'로 변환해 주는 프로토콜

1. 왜 MAC 주소로 변환을 해야할까?

> Note IP 주소만 알면 데이터를 보낼 수 있을 것 같지만, 실제 물리적인 통신 장비(L2 스위치, 랜카드 등)는 IP 주소를 이해하지 못하고 **오직 MAC 주소만 보고 데이터를 전달**합니다.

예시)

IP → 구역(서울특별시 강남구 테헤란로 123)

MAC → 정확한 장소(해당 건물 3층 301호)

# 2. ARP의 동작 원리

1. **ARP 캐시(Table) 확인**

> Note 

  - 가장 먼저 자신의 컴퓨터에 저장된 'ARP 캐시 테이블(기존에 통신했던 IP-MAC 매핑 기록장)'을 뒤져봅니다.

  - 기록이 있으면 바로 통신을 시작하고, 없으면 다음 단계로 넘어갑니다.

1. **ARP Request (요청 - 브로드캐스트)**

> Note 네트워크(동일한 LAN/VLAN)에 연결된 **모든 기기**에게 데이터를 뿌립니다(브로드캐스트).

예시)

"혹시 IP 주소가 192.168.1.50인 사람 있나요? 있으면 저한테 MAC 주소 좀 알려주세요!”

1. **ARP Reply (응답 - 유니캐스트)**

> Note 

  - 해당 IP를 가진 B 컴퓨터만 이 방송에 응답하고, 나머지 기기들은 이 요청을 무시합니다.

  - B 컴퓨터는 A 컴퓨터에게 1:1로(유니캐스트) 답장을 보냅니다.

예시)

"그거 제 IP입니다. 제 MAC 주소는 00:1A:2B:3C:4D:5E 입니다."

1. **통신 시작 및 캐시 저장**

> Note 알아낸 MAC 주소로 L2 프레임 포장을 완료하여 진짜 데이터를 전송하고, 나중을 위해 이 주소 정보를 자신의 ARP 캐시에 일정 시간 동안 저장해 둡니다.
