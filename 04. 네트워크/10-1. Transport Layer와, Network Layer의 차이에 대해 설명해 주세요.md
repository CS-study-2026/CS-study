# 10-1. Transport Layer와, Network Layer의 차이에 대해 설명해 주세요.

## 한 줄 정의

- **Transport Layer(4계층)** : **목적지 컴퓨터까지 데이터를 신뢰성 있게 전달**하는 역할

- **Network Layer(3계층)** : **목적지 컴퓨터까지 데이터를 어떤 경로로 보낼지 결정**하는 역할

즉,

- **Network Layer(3)**는 **"어디로 보낼 것인가?"**

- **Transport Layer(4)**는 **"어떻게 안전하게 보낼 것인가?"**

를 담당합니다.

---

# 비유로 이해하기

택배를 보낸다고 가정해 보겠습니다.

### Network Layer

> **"서울에서 부산까지 어떤 경로로 갈까?"**

- 어느 고속도로를 이용할지

- 어느 물류센터를 거칠지

를 결정합니다.

즉, **배송 경로를 결정**하는 역할입니다.

---

### Transport Layer

> **"택배가 안전하게 도착했는가?"**

- 물건이 빠지지는 않았는지

- 순서대로 도착했는지

- 분실되면 다시 보내야 하는지

를 관리합니다.

즉, **배송 품질을 보장**하는 역할입니다.

---

# 실제 웹 통신에서

브라우저가 Google 서버에 요청을 보낸다고 가정하면,

### ① Network Layer

- 목적지 IP 주소 확인

- 라우팅 테이블 조회

- 다음 Router(Next Hop) 결정

- 목적지까지 경로 선택

---

### ② Transport Layer

- 데이터를 Segment로 분할

- 순서 번호(Sequence Number) 부여

- 오류 검출(Checksum)

- 손실 시 재전송(TCP)

- 흐름 제어(Flow Control)

- 혼잡 제어(Congestion Control)

---

# 가장 큰 차이

| Transport Layer | Network Layer |
| --- | --- |
| **신뢰성 있는 전송** 담당 | **경로 선택(Routing)** 담당 |
| TCP, UDP 사용 | IP 사용 |
| Port 번호 사용 | IP 주소 사용 |
| 데이터를 Segment로 분할 | Packet을 목적지까지 전달 |
| 송신 프로세스 ↔ 수신 프로세스 간 통신 | 송신 호스트 ↔ 수신 호스트 간 통신 |

---

# Port와 IP의 차이

Transport Layer는

**어떤 프로그램에게 데이터를 전달할지**를 결정합니다.

예를 들어

```plain text
192.168.0.10:80
```

- **192.168.0.10** → 어떤 컴퓨터인가? (IP 주소)

- **80** → 그 컴퓨터의 어떤 프로그램인가? (Port 번호)

즉,

- **Network Layer**는 **컴퓨터를 찾고**

- **Transport Layer**는 **그 컴퓨터 안의 애플리케이션을 찾습니다.**

---

# 쉽게 기억하기

```plain text
IP
↓

어느 집으로 갈까?

(Network Layer)

↓

Port

그 집의 몇 호로 갈까?

(Transport Layer)
```

즉,

- **IP = 목적지 컴퓨터**

- **Port = 목적지 프로그램**

입니다.

---

# 면접 답변 예시

> Network Layer는 목적지 IP 주소를 기반으로 데이터가 어떤 경로를 통해 목적지 호스트까지 전달될지를 결정하는 계층입니다. 반면 Transport Layer는 목적지에 도착한 데이터를 올바른 애플리케이션까지 전달하고, TCP를 사용하는 경우 데이터의 순서 보장, 오류 검출, 재전송, 흐름 제어 등을 통해 신뢰성 있는 전송을 담당합니다. 즉, Network Layer는 '어디로 보낼 것인가'를, Transport Layer는 '어떻게 안전하게 전달할 것인가'를 담당한다는 차이가 있습니다.

---

# 예상 꼬리 질문

### Q. IP 주소와 Port 번호의 차이는 무엇인가요?

- **IP 주소**는 목적지 컴퓨터를 식별합니다.

- **Port 번호**는 목적지 컴퓨터에서 실행 중인 애플리케이션을 식별합니다.

예를 들어 `192.168.0.10:443`이라면,

- `192.168.0.10`은 서버의 IP 주소이고,

- `443`은 HTTPS 서비스를 제공하는 포트 번호입니다.

---

### Q. UDP도 Transport Layer인데 신뢰성을 보장하나요?

아닙니다.

Transport Layer에는 **TCP와 UDP**가 있으며,

- **TCP**는 재전송과 순서 보장을 통해 신뢰성을 제공합니다.

- **UDP**는 신뢰성 기능을 제공하지 않는 대신, 오버헤드가 적어 빠른 전송이 가능합니다.
