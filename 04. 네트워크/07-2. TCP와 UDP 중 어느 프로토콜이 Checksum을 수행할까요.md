# 7-2. TCP와 UDP 중 어느 프로토콜이 Checksum을 수행할까요?

## 결론

> **TCP와 UDP 모두 Checksum을 수행합니다.**

---

## TCP의 Checksum

TCP는 신뢰성 있는 통신을 위해 Checksum을 사용합니다.

```plain text
TCP Segment

+----------------+
| TCP Header     |
| Checksum       |
+----------------+
| Data           |
+----------------+
```

수신자가 Checksum을 검증한 후 오류가 없다면 정상적으로 처리하고, 오류가 발견되면 손상된 세그먼트로 판단합니다.

TCP는 손상된 세그먼트를 버리고, ACK를 보내지 않거나 재전송 메커니즘을 통해 올바른 데이터를 다시 받습니다.

---

## UDP의 Checksum

UDP 역시 Checksum을 통해 데이터 손상 여부를 확인합니다.

```plain text
UDP Datagram

+----------------+
| UDP Header     |
| Checksum       |
+----------------+
| Data           |
+----------------+
```

다만 UDP는 **신뢰성을 보장하지 않는 프로토콜**이므로 오류를 발견해도 재전송을 요청하지 않습니다.

---

## TCP와 UDP의 차이

| 항목 | TCP | UDP |
| --- | --- | --- |
| Checksum | O | O |
| 오류 검출 | O | O |
| 재전송 | O | X |
| 신뢰성 | 높음 | 낮음 |

즉,

- **Checksum은 둘 다 수행한다.**

- **재전송은 TCP만 수행한다.**

---

## 면접 답변

> TCP와 UDP 모두 Checksum을 수행합니다. 두 프로토콜 모두 전송 중 데이터가 손상되었는지 확인하기 위해 Checksum을 계산합니다. 하지만 TCP는 오류가 발견되면 재전송을 통해 신뢰성을 보장하는 반면, UDP는 오류를 검출만 하고 재전송은 수행하지 않습니다.
