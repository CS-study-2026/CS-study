# 2-1. 401 (Unauthorized) 와 403 (Forbidden)은 의미적으로 어떤 차이가 있나요?

# 1. 401 Unauthorized (인증 안 됨)

- 신원 미상 (Who are you?)

- 요청자가 누구인지 서버가 확인할 수 없습니다. 즉, 로그인을 하지 않았거나 보낸 보안 토큰(JWT 등)이 유효하지 않은 상태입니다.

- "당신이 누군지 모르겠으니, 먼저 신분증을 보여주세요(로그인하세요)."

# 2. 403 Forbidden (권한 없음)

- 자격 미달 (No Permission)

- 서버가 요청자가 누구인지는 정확히 알고 있습니다. 하지만 그 사용자의 등급이나 권한으로는 해당 리소스에 절대 접근할 수 없도록 서버가 법적으로 금지한 상태입니다.

- "당신이 일반 회원인 것은 알겠습니다. 하지만 여기는 관리자 전용 구역이라 들어올 수 없습니다."

# 3. 401 (Unauthorized) vs 403 (Forbidden)

| **구분** | **401 Unauthorized** | **403 Forbidden** |
| --- | --- | --- |
| **관련 개념** | **Authentication (인증)** | **Authorization (인가/권한)** |
| **발생 조건** | - HTTP 헤더에 Authorization 토큰이 없을 때
- 만료된 JWT 토큰을 보냈을 때 | - 일반 유저가 ` /admin/users` (관리자 페이지) 호출 시
- A라는 사용자가 B라는 사용자의 비공개 글을 수정(`PUT`)하려고 할 때 |
| **해결 방법** | 올바른 아이디/비밀번호로 로그인하여 유효한 토큰을 발급받아 다시 요청한다. | 더 높은 권한(Role)을 부여받거나, 본인이 소유한 데이터에만 접근한다. |
