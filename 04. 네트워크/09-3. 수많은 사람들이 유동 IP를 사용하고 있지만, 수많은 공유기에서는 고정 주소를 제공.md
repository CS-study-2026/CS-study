# 9-3. 수많은 사람들이 유동 IP를 사용하고 있지만, 수많은 공유기에서는 고정 주소를 제공하는 기능이 이미 존재합니다. 어떻게 가능한 걸까요?

# 유동 IP 환경에서 공유기가 고정 IP를 제공할 수 있는 이유

## 유동 IP와 고정 IP의 차이

### 유동 IP (Dynamic IP)

- 인터넷 서비스 제공업체(ISP)의 **DHCP 서버가 일정 기간 동안 임시로 할당**하는 공인 IP 주소입니다.

- 공유기를 재부팅하거나 임대 기간(Lease Time)이 만료되면 IP가 변경될 수 있습니다.

### 고정 IP (Static IP)

- 항상 동일한 IP 주소를 사용하는 방식입니다.

- 서버, CCTV, NAS 등 항상 같은 주소로 접근해야 하는 장비에서 주로 사용됩니다.

---

# 왜 공유기에서는 고정 IP를 설정할 수 있을까?

핵심은 **공유기가 고정시키는 것은 공인 IP가 아니라 내부 사설 IP이기 때문**입니다.

공유기는 내부 네트워크에서 **DHCP 서버 역할**도 수행합니다.

```plain text
인터넷
     │
공인 IP (유동)
     │
 ┌────────────┐
 │   공유기    │  ← DHCP 서버
 └────────────┘
     │
 ├── PC      → 192.168.0.10
 ├── 노트북   → 192.168.0.20
 └── 스마트폰 → 192.168.0.30
```

외부에서는 공인 IP가 바뀔 수 있지만, **공유기 내부에서는 각 기기에 항상 같은 사설 IP를 할당**할 수 있습니다.

---

# 공유기의 "고정 IP" 기능은 어떻게 동작할까?

대부분의 공유기는 **DHCP 예약(DHCP Reservation 또는 Static DHCP)** 기능을 제공합니다.

### 동작 과정

1. 기기가 공유기에 접속하면서 자신의 **MAC 주소**를 전달합니다.

1. 공유기는 MAC 주소를 확인합니다.

1. 미리 등록된 MAC 주소라면 항상 같은 사설 IP를 할당합니다.

예시

| MAC 주소 | 항상 할당되는 IP |
| --- | --- |
| AA:BB:CC:11:22:33 | 192.168.0.10 |
| DD:EE:FF:44:55:66 | 192.168.0.20 |

즉,

> **MAC 주소와 IP 주소를 매핑하여 항상 동일한 사설 IP를 제공하는 방식**입니다.

---

# 공인 IP는 어떻게 될까?

공인 IP는 ISP가 관리합니다.

예를 들어

```plain text
오늘
공인 IP : 121.34.56.78

내일
공인 IP : 211.123.45.67
```

공인 IP는 변경될 수 있지만,

```plain text
PC
192.168.0.10

NAS
192.168.0.20

프린터
192.168.0.30
```

내부 사설 IP는 그대로 유지됩니다.

즉,

- 외부 주소(공인 IP)는 변경될 수 있음

- 내부 주소(사설 IP)는 공유기가 동일하게 유지

---

# 만약 공인 IP도 항상 고정하고 싶다면?

이 경우에는 공유기 설정만으로는 불가능합니다.

ISP로부터 **고정 공인 IP 서비스(Static Public IP)**를 신청해야 합니다.

기업 서버나 웹 서버 운영 시 주로 사용됩니다.

---

# 정리

| 구분 | 설명 |
| --- | --- |
| 유동 공인 IP | ISP가 DHCP를 통해 임시로 할당하며 변경될 수 있음 |
| 공유기의 고정 IP | DHCP 예약 기능으로 MAC 주소에 동일한 사설 IP를 할당 |
| 핵심 원리 | 공유기가 내부 DHCP 서버 역할을 수행하기 때문 |
| 공인 IP를 고정하려면 | ISP에서 고정 공인 IP 서비스를 신청해야 함 |

---

# 면접 핵심 답변

> 공유기에서 제공하는 '고정 IP'는 **공인 IP를 고정하는 것이 아니라, 내부 네트워크에서 DHCP 예약 기능을 이용해 특정 MAC 주소에 항상 동일한 사설 IP를 할당하는 기능**입니다. 반면 공인 IP는 ISP의 DHCP 정책에 따라 변경될 수 있으며, 이를 항상 동일하게 사용하려면 ISP의 **고정 공인 IP 서비스**를 이용해야 합니다.
