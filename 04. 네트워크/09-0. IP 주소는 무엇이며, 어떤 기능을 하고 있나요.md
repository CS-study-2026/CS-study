# 9-0. IP 주소는 무엇이며, 어떤 기능을 하고 있나요?

# 0. IP 주소(IP Address)란?

인터넷이나 네트워크에 연결된 **모든 장치(컴퓨터, 스마트폰, 서버 등)를 식별하기 위해 부여되는 고유한 주소**

→ 사람에게 주민등록번호나 집 주소가 있듯이, 네트워크에서는 각 장치가 IP 주소를 통해 서로를 구분

IP 주소는 **인터넷 프로토콜(IP)**에서 사용하는 주소 체계로, 인터넷상에서 데이터를 정확한 목적지까지 전달하기 위한 핵심 요소 !

- 인터넷 서비스 제공업체(ISP)가 사용자에게 공인 IP를 할당

- 가정이나 회사 내부에서는 공유기를 통해 사설 IP를 사용

---

# 1. IP 주소의 유형

### 1. 공인 IP(Public IP)

- 인터넷에서 사용하는 고유한 IP 주소

- ISP(인터넷 서비스 제공업체)가 할당

- 인터넷상에서 하나만 존재

- 외부와 직접 통신 가능

예시

- 집 공유기 IP

- 회사 인터넷 회선 IP

### 2. 사설 IP(Private IP)

- 가정이나 회사 내부 네트워크에서 사용하는 IP

- 공유기(DHCP)가 각 기기에 자동으로 할당

- 외부 인터넷에서는 직접 접근 불가능

- 여러 네트워크에서 동일한 주소를 사용할 수 있음

대표 주소 범위

| 클래스 | 주소 범위 |
| --- | --- |
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

### 3.  정적 IP(Static IP)

- 사용자가 직접 설정하거나 ISP가 고정으로 할당

- 항상 동일한 IP 사용

- 변경되지 않음

예시

- 웹 서버

- 회사 서버

- CCTV

- 원격 접속 서버

장점

- 항상 같은 주소 사용

- 서버 운영에 적합

단점

- 비용이 비싼 경우가 많음

- 공격 대상이 되기 쉬움

### 4. 동적 IP(Dynamic IP)

- DHCP(Dynamic Host Configuration Protocol)가 자동으로 할당

- 접속할 때마다 IP가 변경될 수 있음

장점

- 관리가 편리

- IPv4 주소를 효율적으로 사용

단점

- IP가 변경되어 서버 운영에는 부적합

---

# 2. IP 주소의 종류

-  IPv4

  - `32비트` 주소 체계

  - 약 43억 개의 주소 표현 가능

  - 가장 널리 사용되는 방식

```plain text
192.168.0.1
```

-  IPv6

  - `128비트` 주소 체계

  - IPv4 주소 부족 문제를 해결하기 위해 개발

  - 사실상 무한에 가까운 주소 제공

```plain text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

---

# 3. IP 주소의 기능

### 1. 네트워크 장치 식별(Identification)

: IP 주소는 네트워크에 연결된 장치를 서로 구분

예를 들어

- 내 노트북

- 스마트폰

- 프린터

- 웹 서버

모두 서로 다른 IP 주소를 가지고 있어 어떤 장치와 통신하는지 구분

### 2. 데이터 전달(Routing)

: IP 주소의 가장 중요한 역할은 **데이터를 올바른 목적지까지 전달하는 것**

인터넷에서 데이터를 전송할 때에는

- 출발지(Source IP)

- 목적지(Destination IP)

를 함께 포함하여 전송

라우터(Router)는 목적지 IP를 확인한 후 가장 적절한 경로를 선택하여 데이터를 전달

```plain text
사용자(192.168.0.10) : Source IP
        │
        ▼
공유기(공인 IP 보유)
        │
        ▼
인터넷
        │
        ▼
웹 서버(203.xxx.xxx.xxx) : Destination IP
        │
        ▼
응답 데이터 반환
```

- 사용자가 웹사이트에 접속

- 요청 데이터에 출발지와 목적지 IP 주소가 포함

- 라우터가 목적지 IP를 확인하여 데이터를 전달

- 웹 서버는 요청을 처리한 후 출발지 IP로 응답(사용자의 IP 주소를 목적지로 하여 )

### 3. 송신자와 수신자 확인

네트워크 통신에서는 `누가 누구에게` 데이터를 보내는지 알아야 함

IP 주소는 이러한 **출발지와 목적지를 지정하는 역할**을 수행하여 정상적인 통신이 가능하도록 함

### 4. 네트워크 위치 정보 제공

: 어느 네트워크에 속해 있는지

- 국내인지 해외인지

- 어느 ISP를 사용하는지

- 어느 네트워크 대역인지

등을 확인할 수 있으며, 일부 서비스에서는 이를 이용해 지역 기반 서비스를 제공,

다만 IP만으로 사용자의 정확한 위치를 알 수 있는 것은 아님!

### 5. 인터넷 서비스 제공

웹사이트 접속, 이메일 송수신, 온라인 게임, 영상 스트리밍 등 인터넷의 모든 서비스는 IP 주소 기반 통신

예를 들어 브라우저에서

```plain text
www.google.com
```

입력 시 DNS가 해당 도메인에 대응하는 IP 주소를 찾아주고, 이후 그 IP 주소를 이용하여 서버와 통신

---

# 4. 요약

> 

IP 주소는 인터넷에 연결된 모든 장치를 식별하고, **데이터가 올바른 목적지까지 전달되도록 하는 주소 체계**

인터넷에서 웹사이트에 접속하거나 이메일을 보내면 데이터에는 **출발지(Source IP)**와 **목적지(Destination IP)**가 함께되며, 네트워크의 **라우터(Router)**는 목적지 IP를 확인하여 가장 적절한 경로를 선택하고 데이터를 전달

즉, IP 주소는 단순히 장치를 구분하는 번호가 아니라 **인터넷에서 데이터를 목적지까지 안내하는 역할**

# 5. 기타

# IP 주소 관련 보안 위협

IP 주소가 노출되면 다음과 같은 위험이 발생할 수 있습니다.

- 위치 정보 추정

- DDoS 공격 대상

- 네트워크 스캔 및 해킹 시도

- 온라인 활동 추적

- 소셜 엔지니어링 공격

# IP 주소 보호 방법

- **VPN** 사용

- **프록시 서버** 사용

- **동적 IP** 사용

- **NAT(Network Address Translation)**를 이용해 사설 IP 숨기기

- 모뎀 또는 공유기 재부팅(동적 IP 환경에서 IP 변경 가능)
