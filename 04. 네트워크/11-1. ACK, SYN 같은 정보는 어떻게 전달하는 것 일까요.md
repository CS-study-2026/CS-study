# 11-1. ACK, SYN 같은 정보는 어떻게 전달하는 것 일까요?

## TCP 헤더의 제어 플래그(Control Flags) 필드

`SYN`이나 `ACK`는 별도의 독립된 패킷이 아니라, 전송 계층에서 생성되는 `TCP 헤더(TCP Header)` 내부의 특정 필드에 **기록되는 데이터**

TCP 헤더의 기본 크기는 20바이트이며, 이 중에는 6비트(또는 확장 규격에 따라 9비트) 크기의 `제어 플래그(Control Bits/Flags)`라는 영역이 존재합니다. 이 영역은 각각 1비트 크기를 가진 여러 개의 스위치(비트 플래그)로 구성되어 있습니다.

### 플래그의 전달 방식

컴퓨터는 이 1비트 공간의 값을 0 또는 1로 설정하여 정보를 전달합니다.

- 비트가 0이면: 해당 기능이 비활성화됨.

- 비트가 1이면: 해당 기능이 활성화됨.

제어 플래그 영역에 존재하는 대표적인 비트들은 다음과 같습니다.

| **플래그 명칭** | **역할** | **설명** |
| --- | --- | --- |
| `SYN` (Synchronize) | 동기화 | 연결을 시작할 때 시퀀스 번호를 동기화하자는 요청입니다. |
| `ACK` (Acknowledgment) | 확인 응답 | 패킷을 정상적으로 수신했음을 알리는 응답입니다. |
| `FIN` (Finish) | 종료 | 데이터 전송이 끝나고 연결을 정상적으로 종료하겠다는 요청입니다. |
| `RST` (Reset) | 강제 리셋 | 연결 도중 심각한 오류가 발생하여 연결을 강제로 끊겠다는 신호입니다. |

결론적으로, 클라이언트나 서버의 운영체제는 네트워크로 패킷을 내보내기 전 TCP 헤더의 플래그 영역에서 `SYN` 비트나 `ACK` 비트를 1로 켜서 전송하며, 상대방은 수신한 패킷의 헤더 영역을 파싱(해석)하여 이 정보들을 인지하게 됩니다.
