# 9-1. IPv6는 IPv4의 주소 고갈 문제를 해결하기 위해 만들어졌지만, 아직도 수많은 기기가 IPv4를 사용하고 있습니다. 고갈 문제를 어떻게 해결할 수 있을까요?

# IPv4 주소 고갈 문제 해결 방법

## IPv4 주소 고갈이란?

IPv4는 **32비트 주소 체계**를 사용하며, 약 **43억 개(2³²)**의 주소를 표현할 수 있습니다. 인터넷 사용 기기(PC, 스마트폰, IoT 등)가 급격히 증가하면서 사용할 수 있는 공인 IPv4 주소가 부족해졌습니다.

IPv6는 이러한 문제를 해결하기 위해 등장했지만, 기존 시스템과의 호환성 때문에 아직도 IPv4가 널리 사용되고 있습니다.

---

# IPv4 주소 고갈 해결 방법

## 1. NAT (Network Address Translation)

NAT는 **여러 개의 사설 IP 주소를 하나의 공인 IP 주소로 변환하여 인터넷과 통신하는 기술**입니다.

### 동작 방식

```plain text
PC1 (192.168.0.2)
PC2 (192.168.0.3)
PC3 (192.168.0.4)
        │
        ▼
     공유기(NAT)
        │
공인 IP : 123.45.67.89
        │
     인터넷
```

- 내부 기기들은 각각 사설 IP를 사용합니다.

- 외부 인터넷과 통신할 때는 공유기가 하나의 공인 IP로 변환하여 통신합니다.

- 따라서 **여러 기기가 하나의 공인 IP를 공유**할 수 있습니다.

### 장점

- 공인 IP 사용량 감소

- IPv4 주소 부족 완화

- 내부 네트워크를 외부에서 직접 접근하기 어려워 보안성이 향상됨

---

## 2. 사설 IP(Private IP) 사용

인터넷에서 직접 사용하지 않는 **사설 IP 대역**을 내부 네트워크에서 사용합니다.

### 사설 IP 대역

| 클래스 | 주소 범위 |
| --- | --- |
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

예를 들어 집이나 회사에서는 모든 기기가 사설 IP를 사용하고, 외부 인터넷과 통신할 때만 NAT를 통해 공인 IP로 변환됩니다.

---

## 3. CIDR (Classless Inter-Domain Routing)

과거에는 클래스(A, B, C) 단위로 IP를 할당하여 주소가 많이 낭비되었습니다.

CIDR은 **필요한 만큼만 IP 주소를 할당**하여 주소 낭비를 줄이는 방식입니다.

### 예시

기존 방식

- 회사에 A 클래스 하나를 할당

- 실제로는 수천 개만 사용

- 나머지 수백만 개 주소 낭비

CIDR 방식

- 필요한 개수만큼 `/24`, `/26`, `/28` 등으로 나누어 할당

- 주소를 훨씬 효율적으로 사용 가능

---

## 4. IPv6 도입 (근본적인 해결책)

IPv6는 IPv4의 주소 부족 문제를 해결하기 위해 만들어졌습니다.

### IPv4와 IPv6 비교

| IPv4 | IPv6 |
| --- | --- |
| 32비트 | 128비트 |
| 약 43억 개 주소 | 거의 무한대(2¹²⁸) |
| 주소 부족 | 주소 부족 문제 해결 |

IPv6는 매우 많은 주소를 제공하지만, 기존 IPv4 장비 및 서비스와의 호환성 문제로 인해 현재는 **IPv4와 IPv6를 함께 사용하는(Dual Stack)** 환경이 일반적입니다.

---

# 정리

| 해결 방법 | 설명 |
| --- | --- |
| **NAT** | 여러 사설 IP를 하나의 공인 IP로 변환하여 공인 IP 사용량 감소 |
| **사설 IP 사용** | 내부 네트워크에서 사설 IP를 사용하고 외부 통신 시 NAT 사용 |
| **CIDR** | 필요한 만큼만 IP를 할당하여 주소 낭비 방지 |
| **IPv6** | 128비트 주소 체계를 사용하여 주소 부족 문제를 근본적으로 해결 |

---

# 면접 핵심 답변

> IPv4 주소 고갈 문제는 **NAT와 사설 IP를 이용해 여러 기기가 하나의 공인 IP를 공유하도록 하여 해결**하고 있습니다. 또한 **CIDR을 통해 IP 주소를 효율적으로 할당하여 낭비를 줄이고**, 장기적으로는 **128비트 주소 체계를 사용하는 IPv6를 도입하여 근본적으로 주소 부족 문제를 해결**하고 있습니다.

## 핵심 키워드

- **NAT** → 공인 IP 공유

- **사설 IP** → 내부 네트워크 사용

- **CIDR** → IP 주소 효율적 할당

- **IPv6** → 근본적인 해결책
