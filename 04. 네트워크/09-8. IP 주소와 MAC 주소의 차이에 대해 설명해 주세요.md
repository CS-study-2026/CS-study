# 9-8. IP 주소와 MAC 주소의 차이에 대해 설명해 주세요.

> **IP 주소와 MAC 주소는 모두 네트워크 통신에 사용되는 주소이지만, 역할과 계층이 다릅니다.**

IP 주소는 네트워크 상에서 목적지를 찾기 위한 **논리적 주소**로, 라우터가 패킷을 전달할 때 사용하는 주소입니다. 반면 MAC 주소는 네트워크 인터페이스 카드에 부여된 **물리적 주소**로, 같은 LAN에서 실제 장치를 식별하는 데 사용됩니다.

실제 통신에서는 먼저 IP 주소를 통해 목적지를 결정하고, ARP 프로토콜을 이용해 해당 IP에 대응하는 MAC 주소를 알아낸 뒤 프레임을 전송합니다.

따라서 **IP는 '어디로 보낼지'를 결정하는 주소이고, MAC은 '어떤 장치에 전달할지'를 결정하는 주소**라고 이해하면 됩니다.

## 1️⃣ IP 주소와 MAC 주소란?

네트워크에서 데이터를 전달하기 위해서는

두 가지 주소가 필요하다.

- **IP 주소** : 목적지를 찾기 위한 **논리적 주소(Logical Address)**

- **MAC 주소** : 실제 장치를 식별하는 **물리적 주소(Physical Address)**

---

## 2️⃣ IP 주소(IP Address)

### 📌 정의

네트워크 상에서 **호스트를 식별하기 위한 논리적인 주소**

운영체제나 네트워크 환경에 따라 변경될 수 있다.

예시

```plain text
192.168.0.10
```

또는

```plain text
2001:db8::1
```

(IPv6)

---

### 📌 특징

- 논리적 주소

- 변경 가능

- 라우팅에 사용

- 네트워크 계층(L3)

---

## 3️⃣ MAC 주소(MAC Address)

### 📌 정의

네트워크 인터페이스 카드(NIC)에 부여된 **고유한 물리 주소**

예시

```plain text
00:1A:2B:3C:4D:5E
```

---

### 📌 특징

- 물리적 주소

- 일반적으로 변경되지 않음 (운영체제에서 MAC 주소를 변경(MAC Spoofing)하여 사용할 수도 있다.)

- 같은 LAN에서 장치 식별

- 데이터 링크 계층(L2)

---

## 4️⃣ IP와 MAC은 어떻게 함께 사용될까?

예를 들어,

내 PC가 같은 네트워크의 다른 PC에게 데이터를 보낼 때

```plain text
브라우저
   ↓
IP 주소 확인
   ↓
ARP 요청
   ↓
MAC 주소 획득
   ↓
프레임 전송
```

즉,

IP 주소로 목적지를 찾고,

ARP(Address Resolution Protocol)를 이용해
해당 IP에 대응하는 MAC 주소를 알아낸 후

실제로 데이터를 전송한다.

※ ARP: 같은 LAN(Local Area Network)에서 IP 주소에 대응하는 MAC 주소를 알아내기 위한 프로토콜

---

## 5️⃣ IP 주소와 MAC 주소 비교

| 구분 | IP 주소 | MAC 주소 |
| --- | --- | --- |
| 의미 | 논리적 주소 | 물리적 주소 |
| 계층 | Network Layer (L3) | Data Link Layer (L2) |
| 변경 가능 여부 | 가능 | 일반적으로 불가능 |
| 사용 목적 | 목적지 탐색(라우팅) | 실제 장치 식별 |
| 예시 | 192.168.0.10 | 00:1A:2B:3C:4D:5E |

---

## 6️⃣ 왜 둘 다 필요할까?

비유하면,

- **IP 주소**는 **집 주소**

- **MAC 주소**는 **집 안의 특정 사람의 주민등록번호**와 비슷하다.

택배를 보낼 때
집 주소(IP)로 목적지를 찾고,

도착한 후에는
해당 장치(MAC)를 찾아 데이터를 전달한다.

---

## 📌 핵심 정리

- **IP 주소**는 네트워크 상의 목적지를 찾기 위한 **논리적 주소**이다.

- **MAC 주소**는 네트워크 인터페이스를 식별하는 **물리적 주소**이다.

- IP는 라우팅에 사용되고, MAC은 같은 LAN에서 실제 장치를 식별하는 데 사용된다.

- 실제 통신에서는 **ARP를 통해 IP 주소를 MAC 주소로 변환**하여 데이터를 전송한다.
