# 9-7. TTL(Hop Limit)이란 무엇인가요?

# 0. TTL(Hop Limit)이란?

**TTL(Time To Live)**은 **IP 패킷이 네트워크에서 무한히 돌아다니는 것을 방지하기 위한 값**

IPv4에서는 **TTL**, IPv6에서는 같은 개념을 **Hop Limit**

> **라우터를 하나 지날 때마다 TTL이 1씩 감소하며, TTL이 0이 되면 패킷은 폐기**

---

# 1. 왜 필요한가?

만약 라우팅 오류가 발생하면 패킷이 무한히 반복될 수 있음

```plain text
A → B → C → A → B → C → ...
```

이렇게 되면

- 네트워크 대역폭 낭비

- 라우터 부하 증가

- 정상적인 통신 방해

가 발생

TTL은 이러한 **무한 루프(Routing Loop)**를 방지하기 위해 존재

---

# 2. 동작과정

예를 들어 TTL = 4인 패킷을 전송하면

```plain text
송신자 (TTL=4)
      │
      ▼
Router1 (TTL=3)
      │
      ▼
Router2 (TTL=2)
      │
      ▼
Router3 (TTL=1)
      │
      ▼
Router4 (TTL=0)
      │
      ▼
패킷 폐기
```

**각 Router는 TTL 패킷이 날라올 떄 , TTL Value를 1씩 감소시키며,**

TTL이 0이 되면 더 이상 전달하지 않고 버림

(기본적으로 초기 Windows의 TTL값은 128)

---

# 3. TTL이 0이 되면?

라우터는

- 패킷 폐기

- 송신자에게 **ICMP Time Exceeded** 메시지 전송

이 때문에 패킷이 왜 목적지에 도착하지 못했는지 송신자가 알 수 있습니다.

=> 자주 사용하는 `ping` 이나 `tracert`가 TTL을 사용함

(특정 호스트 **컴퓨터에 접근을 시도하거나 그 호스트까지의 경로를 추적**할 때)

<details>
<summary>tracert 명령어에서의 동작 원리</summary>

1. TTL = 1로 패킷 전송

    - 첫 번째 라우터에서 TTL이 0이 되어 폐기

    - 첫 번째 라우터가 ICMP 응답 전송

  1. TTL = 2로 전송

    - 두 번째 라우터에서 폐기

  1. TTL = 3로 전송

    - 세 번째 라우터에서 폐기

...

이 과정을 반복하여 **패킷이 거치는 모든 라우터(홉, Hop)**를 확인
</details>

---

# 4. Hop이란?

**패킷이 하나의 라우터를 통과하는 것**

예를 들어

```plain text
PC
 │
 ▼
Router1   (1 Hop)
 │
 ▼
Router2   (2 Hop)
 │
 ▼
Router3   (3 Hop)
 │
 ▼
Server
```

총 **3 Hop**을 거쳐 목적지에 도착

---

# 5. 면접용 요약 및 꼬리질문 대비

<details>
<summary>면접 꼬리질문</summary>

### Q. TTL은 시간이 줄어드는 값인가요?

**아닙니다.**

이름은 Time To Live지만 실제로는 **시간이 아니라 라우터(Hop)를 지날 때마다 감소하는 카운터**입니다.

---

### Q. TTL이 필요한 이유는?

→ **라우팅 루프(Routing Loop)를 방지하기 위해서입니다.**

---

### Q. TTL이 0이 되면 어떻게 되나요?

→ **패킷을 폐기하고 ICMP Time Exceeded 메시지를 송신자에게 전송합니다.**

---

### Q. traceroute는 TTL을 어떻게 활용하나요?

→ TTL 값을 1부터 차례대로 증가시키며 패킷을 전송하고, 각 홉에서 반환되는 **ICMP Time Exceeded** 메시지를 이용해 경로상의 라우터를 확인합니다.
</details>

TTL(Time To Live)은 IP 패킷이 네트워크에서 무한히 순환하는 것을 방지하기 위한 값입니다.

패킷이 라우터를 하나 통과할 때마다 TTL이 1씩 감소하며, TTL이 0이 되면 라우터는 해당 패킷을 폐기하고 송신자에게 ICMP Time Exceeded 메시지를 보냅니다.

IPv6에서는 동일한 개념을 Hop Limit이라고 부르며, traceroute 명령어도 TTL을 이용해 목적지까지의 라우터 경로를 확인합니다.
